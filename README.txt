ZIHAD NET website

Files:
- index.html: complete responsive website

Free publishing:
1. Create a free account at GitHub.
2. Create a public repository named zihad-net.
3. Upload index.html.
4. In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. GitHub will provide a free website address ending in github.io.

The website has no online payment, customer login, or admin panel. The offer section uses general wording because no specific discount/offer details were provided.
